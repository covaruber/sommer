# anova form a GLMM fitted with mmes

`anova` method for class `"mmes"`.

## Usage

``` r
# S3 method for class 'mmes'
anova(object, object2=NULL, ...)
```

## Arguments

- object:

  an object of class `"mmes"`

- object2:

  an object of class `"mmes"`, if NULL the program will provide regular
  sum of squares results.

- ...:

  Further arguments to be passed

## Value

vector of anova
